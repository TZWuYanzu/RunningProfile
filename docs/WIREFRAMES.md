## 关键交互说明

1. **日历 ↔ 教练联动**：点击日历的「让教练生成计划」按钮，跳转教练 Tab 并预填 prompt
2. **计划卡片可点击**：教练对话中的计划卡片底部有「查看日历」按钮，跳转日历 Tab
3. **对话时间线连续**：没有"新建对话"入口，只有一条连续的时间线，日期分隔符标注间隔
4. **工具调用可见**：教练调用工具时显示折叠卡片（如 📊 get_recent_activities），用户可展开查看原始数据
5. **周总结主动推送**：每周一早上教练主动在时间线中发出周总结，用户打开时看到
