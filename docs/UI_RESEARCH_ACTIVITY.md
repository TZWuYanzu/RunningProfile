# 竞品 UI 调研：运动历史列表 · 运动详情 · 分享功能

> 调研日期：2026-06-11
> 调研对象：DIGRUN、Sigma、COROS、Garmin Connect、Suunto、Strava
> 数据来源：App Store 截图 + 功能描述 + 用户评价

---

## 调研目标

从三个维度横向对比各竞品的设计模式：

1. **运动历史列表** — 用户如何浏览和回顾历史运动
2. **单次运动详情** — 运动完成后展示哪些数据、如何布局
3. **分享功能** — 如何生成和自定义分享卡片

---

## 一、逐产品分析

### 1. DIGRUN（潮流跑者 App）

**定位**："来自DIGRUN跑步媒体，专为潮流跑者打造" / "Beyond Running"
**背景**：母公司做潮流球鞋（盯潮），从潮流赛道切入跑步
**评分**：4.9/5（977评分），设计是核心卖点

#### 运动历史列表
- **主入口**："记录"页面，暗色系
- **视觉焦点**：城市轨迹地图占据上半屏（所有跑步GPS轨迹叠加在城市地图上，荧光绿线条），非常有视觉冲击力
- **时间维度切换**：顶部 Tab — 本周 / 月 / 年 / 总
- **汇总数据**：地图下方三个大数字 — 总距离(121.8K) / 总用时(1213h) / 总次数(312)
- **列表区域**：下方"最近"区域展示近期运动条目
- **设计特点**：地图轨迹作为"个人足迹名片"的概念，强调"让足迹成为表达"

#### 单次运动详情
- **顶部**：全宽 GPS 轨迹地图（暗色地图底图 + 荧光绿路线），有 2D/3D 切换（越野支持 3D 轨迹展示）
- **核心数据**：超大字体距离数字（如 21.37km），下方标注运动类型 + 日期 + 来源设备（如 COROS PACE 2）
- **PB 标记**：右侧显眼的 `{ PB }` 徽章
- **数据网格**：2列布局
  - 跑步时长 | 平均配速
  - 平均心率 | 最大心率
- **AI 分析入口（PACER AI）**：
  - 顶部切换 Tab："分享" / "深度分析"
  - 跑者画像：文字描述用户身体数据和运动特征
  - 数据总览 + 强度/配位分析 + 关键指标
  - 标语："AI 分析，读懂身体与节奏"
- **整体风格**：纯暗色背景，荧光绿点缀，大字体，留白充足，很"潮"

#### 分享功能
- **独立"分享中心"模块**（非详情页附属功能，是产品级特性）
- **多模板体系**：
  - 摄影风模板：用户跑步照片 + 数据叠加
  - 纯数据风模板：大字体距离/时间 + 极简背景
  - 轨迹线条风：GPS轨迹艺术化展示
  - 月报卡片：月度跑量汇总
- **自定义贴纸系统**：用户可选择哪些数据显示在卡片上（心率、配速、时长、轨迹等可编辑）
- **品牌联名模板**：如悦木之源联名分享模板
- **越野 3D 轨迹分享**：越野跑支持 3D 立体轨迹卡片
- **设计理念**："风格结算，每次跑步都值得分享"
- **关键洞察**：DIGRUN 把分享做成了产品核心环节，不是"附加功能"而是"跑完的仪式感"

### 2. Sigma（AI 跑步记录）

**定位**："一群爱跑步的设计师" / "汗水 风声 成为自己"
**评分**：4.8/5（769评分）

#### 运动历史列表
- **数据概览页**：以统计视图为核心（非传统列表）
  - 大字体总里程（246.32km）
  - 平均配速 / 总消耗 / 平均步数 / 平均公里 / 连续运动天数
  - 3D 岩石/山丘可视化代表总里程（趣味视觉）
- **时间维度**：周 / 月 / 年 Tab 切换
- **周数据图表**：柱状图展示每日跑量
- **日历视图**：日历格子中用 emoji/心情标记每天运动状态，兼具"跑步日记"属性
- **趣味化**：配速对标动物世界（猎豹/麋鹿/斑马/兔子），不同配速区间对应不同动物图标
- **设计特点**：数据不是冷冰冰的表格，而是趣味化、情绪化的呈现

#### 单次运动详情
- **运动中界面**：
  - 纯暗色背景，GPS 地图实时显示
  - 超大字体：时间（03:52:06）、距离（42.2km）
  - 辅助数据：实时配速（5'30"）、卡路里（2025）
  - AI 气泡提示："5天没运动了，是时候突破自己了"（主动对话入口）
- **跑后 AI 分析**（Sig AI）：
  - 聊天对话界面，AI 有可爱表情头像
  - 显示"已读取 Sigma x 北体知识库" → "已思考完成"的加载过程
  - 分析内容：配速波动分析、心率负荷解读、跑姿分析（步频图表）
  - 跑步表现 + 可能原因 + 改进建议
  - 陌生专业名词有下划线解释
- **健康档案侧边栏**：性别、身高体重、静息心率、心率变异性、排跑量

#### 分享功能
- **3D 立体动效轨迹分享卡**：GPS 轨迹做成 3D 立体效果
- **品牌联名卡**：阿迪达斯联名分享卡
- **碎片彩蛋分享**：徽章铁盒中的碎片可分享
- **天气联动记忆戳**：跑步时的天气状态融入分享内容
- **Moment 拍摄**：跑步中拍照记录瞬间，可融入分享

### 3. COROS（高驰）

**定位**：专业运动手表配套 App / "刷新你的训练"
**评分**：4.6/5（2595评分）

#### 运动历史列表
- **首页 = 今日仪表盘**：
  - 日期 + 周几（如"8月14日 星期四"）
  - 周活动量推荐区间提示（推荐值 210-378）
  - 本周每日活动量柱状图（周一到周日）
- **训练负荷卡片**：
  - 训练量评估状态（如"高效训练"）
  - 短期负荷 / 长期负荷 / 负荷比（120 / 100 / 120%）
  - 过去7天柱状趋势图
- **体力恢复**：百分比 + 人体轮廓图
- **睡眠卡片**：时长 + 质量评分
- **HRV 评估**：偏低/正常范围指示
- **设计特点**：功能性优先，信息密度高，卡片式布局，纸张质感背景

#### 单次运动详情
- **顶部**：卫星地图（支持地形图），轨迹线 + 打点标记（km 标记点）
  - 越野跑示例：黄山市越野跑，48.32km
  - 地图可切换 2D/卫星/地形视图
- **核心数据网格**：2-3列布局
  - 总时间（5:26:55）
  - 配速（6'46"）/ 移动配速（5'50"）
  - 平均心率（155）/ 爬升（1940m）
  - 岩石地形标记（Rock 图标）
- **特色数据**：
  - 地形分析（Rock/Trail 等标记）
  - 移动配速 vs 总配速区分
  - 爬升/下降独立展示
- **扩展屏功能**：手机可作为手表扩展屏，实时显示心率、配速、距离等
- **自定义运动界面**：手表显示字段可在 App 中编辑

#### 分享功能
- **基础分享**：标准运动数据截图式分享
- **无专门分享卡片设计系统**
- **重点在数据导出**：支持导出到 Strava、Keep、悦跑圈等 10+ 个第三方平台

#### 其他亮点
- **装备记录**：跑鞋/自行车里程追踪，品牌+型号+进度条
- **训练计划**：免费下载训练计划，一键推送到手表
- **路线规划**：卫星地图规划路线 + 海拔剖面图，一键推送到手表

### 4. Garmin Connect（佳明）

**定位**：健康与运动数据管理平台
**评分**：3.0/5（5340评分）— 评分偏低，主要因 UI 老旧

#### 运动历史列表
- **首页 = 今日活动**：
  - "Today's Activity" 卡片：运动类型图标 + 距离 + 时间 + 配速 + 迷你轨迹缩略图
  - "In Focus" 区域：突出一个重点数据（如 Sleep Score）
  - "At a Glance" 区域：多个健康指标小卡片
- **蓝色品牌色背景**，深色卡片，白色文字
- **设计偏传统**：Android Material Design 风格，功能全但视觉老旧

#### 单次运动详情
- **信息密度极高**：从截图推断
  - 配速、距离、心率、步频等标准数据
  - Body Battery 消耗/恢复
  - 睡眠质量对运动影响的关联分析
- **详情子页面**：每个指标都有独立详情页
  - Sleep Score：分数 + 质量 + 时长 + 文字解读 + 时间线/阶段图表
  - Body Battery：环形进度 + 文字评估 + 充放电值 + 日时间线
  - Hydration：环形进度 + 快捷添加
- **文字解读**：每个数据都附带一段自然语言解读（如 "Highly restorative. You had extremely restorative sleep."）
- **时间维度切换**：1d / 7d / 4w / 1y

#### 分享功能
- **基础截图式分享**，无专门设计的分享卡片系统
- **强项在数据深度**，弱项在视觉表现
- **设计痛点**：功能极丰富但 UI 缺乏现代感和趣味性，用户评分低是佐证

### 5. Suunto（颂拓）

**定位**：户外探险 + 运动训练全能伴侣
**评分**：4.6/5（4579评分）

#### 运动历史/详情（基于功能描述，无截图）
- 90+ 运动类型覆盖
- 训练负荷与趋势分析图表
- Suunto 智能教练提供见解和建议
- 2D / 3D 地图展示（全球运动热力图）
- SuuntoPlus Guides：实时运动指导

#### 分享功能
- **个性化分享数据选择**：用户可选择是否分享距离、热量、速度、配速、时长、心率等数据项
- 分享到 Strava、微信运动、Keep、悦跑圈等多平台

### 6. Strava（参考标杆）

**定位**：全球最大运动社交平台
**特点**：以运动社交 + Segment 竞赛为核心

#### 运动历史列表（基于产品认知）
- **Feed 流式设计**：类似社交媒体的信息流
- **每条活动卡片**：
  - 用户头像 + 名字 + 时间
  - 地图轨迹缩略图
  - 核心数据：距离 / 时间 / 配速
  - 爬升（如有）
  - 社交互动：Kudos（点赞）/ 评论
  - Segment 成绩标记

#### 单次运动详情
- **地图轨迹**（占大面积）+ Segment 高亮
- **数据面板**：配速/心率/爬升/步频/功率
- **分段数据表格**：每公里配速 + 心率
- **Segment 排名**：当前成绩在该路段的排名
- **Relative Effort / Suffer Score**

#### 分享功能
- **经典分享卡片**：简洁的运动数据 + 地图轨迹
- **社交传播**：直接发布到 Feed 供好友互动
- **Strava Art**：通过跑步轨迹画图（社区自发玩法）

## 二、横向对比总结

### 2.1 运动历史列表设计模式

| App | 主要模式 | 视觉核心 | 时间维度 | 创新点 |
|-----|---------|---------|---------|-------|
| DIGRUN | 轨迹地图 + 统计 + 列表 | 城市轨迹叠加图 | 周/月/年/总 | 所有轨迹叠加成"足迹名片" |
| Sigma | 统计概览 + 日历 | 趣味数据可视化 | 周/月/年 | 配速动物对标 + 心情日历 |
| COROS | 今日仪表盘 + 卡片 | 训练负荷/恢复指标 | 日维度为主 | 训练状态评估前置 |
| Garmin | 今日活动 + 健康指标 | 功能卡片堆叠 | 日/周/月/年 | 数据最全但视觉最弱 |
| Strava | 社交 Feed 流 | 轨迹缩略图 + 社交 | 时间线 | Segment + 社交互动 |

**设计趋势总结**：
- 潮流类（DIGRUN/Sigma）：**弱化列表，强化视觉概览**。用地图/图表/趣味元素取代传统的"一条条记录"
- 设备类（COROS/Garmin）：**仪表盘优先**。首页展示今日训练状态而非历史列表
- 社交类（Strava）：**Feed 流**。每条活动是一张"社交帖子"

### 2.2 单次运动详情页设计模式

| App | 地图位置 | 核心数据布局 | AI/分析 | 特色元素 |
|-----|---------|-----------|--------|---------|
| DIGRUN | 全宽顶部 | 大距离 + 2列网格 | PACER AI 深度分析 | PB 徽章、设备来源标记 |
| Sigma | 全屏实时地图 | 超大时间/距离 | Sig AI 对话式分析 | AI主动气泡、专业名词解释 |
| COROS | 全宽卫星/地形图 | 多列数据网格 | 无 AI 分析 | 地形标记、移动配速、扩展屏 |
| Garmin | 标准地图 | 卡片式子页面 | 文字解读每项指标 | Body Battery、深度子页面 |
| Strava | 全宽地图 | 数据面板 + 分段表 | Relative Effort | Segment 排名、社交互动 |

**设计趋势总结**：
- **地图永远在最上面**，是视觉锚点
- 潮流类用**超大字体数字**营造冲击力
- AI 分析正在成为标配：DIGRUN（PACER AI）、Sigma（Sig AI）都已上线
- 设备类在数据深度上碾压，但视觉吸引力不足

### 2.3 分享功能设计模式

| App | 分享等级 | 模板数量 | 自定义程度 | 特色 |
|-----|---------|---------|----------|------|
| **DIGRUN** | ⭐⭐⭐⭐⭐ 产品级 | 多种风格 | 数据贴纸可编辑 | 品牌联名、3D越野、月报卡片 |
| **Sigma** | ⭐⭐⭐⭐ 重要功能 | 多种 | 中等 | 3D动效轨迹、品牌联名、碎片彩蛋 |
| **Strava** | ⭐⭐⭐ 标准功能 | 少量 | 低 | 社交 Feed 传播、Strava Art |
| **COROS** | ⭐⭐ 基础 | 基本无 | 低 | 重在第三方数据同步 |
| **Garmin** | ⭐ 基础 | 无 | 低 | 截图级别 |
| **Suunto** | ⭐⭐ 基础 | 无 | 数据项可选 | 数据项选择性分享 |

**设计趋势总结**：
- **分享卡片的精致程度与产品调性直接挂钩**。面向潮流用户的 App 把分享做成核心仪式
- 设备厂商 App 几乎不投入分享卡片设计（它们认为分享是第三方平台的事）
- DIGRUN 最激进：分享中心是独立功能模块，支持多模板+自定义贴纸+品牌联名

## 四、对我们产品的设计启示

### 4.1 运动历史列表：推荐方案

**不做传统列表，做"视觉概览 + 智能列表"**

借鉴 DIGRUN 的轨迹地图 + Sigma 的趣味统计：

```
┌─────────────────────────────┐
│  [城市轨迹/热力图]           │  ← 所有轨迹叠加，视觉冲击
│  (支持2D/3D/卫星切换)        │
├─────────────────────────────┤
│  总里程    总爬升    总次数    │  ← 大字体核心统计
│  2,225km   63,630m   190     │
├──────┬──────┬──────┬────────┤
│ 本周  │  月  │  年  │  总    │  ← 时间维度Tab
├──────┴──────┴──────┴────────┤
│  [周跑量柱状图/趋势图]       │
├─────────────────────────────┤
│  ◉ 教练洞察                  │  ← 我们的差异化：AI总结
│  "本周训练负荷偏高，建议..."  │
├─────────────────────────────┤
│  最近运动                    │
│  ┌───────────────────────┐  │
│  │ 🏔 越野跑 · 6月10日     │  │  ← 卡片式，地图缩略图
│  │ 15.3km  D+820m  1:42  │  │     越野突出爬升
│  │ [迷你轨迹图]            │  │
│  └───────────────────────┘  │
│  ┌───────────────────────┐  │
│  │ 🏃 路跑 · 6月8日        │  │
│  │ 10.0km  5'12"/km 52min│  │     路跑突出配速
│  │ [迷你轨迹图]            │  │
│  └───────────────────────┘  │
└─────────────────────────────┘
```

**关键设计决策**：
- 越野跑卡片突出**爬升(D+)**，路跑卡片突出**配速**——根据运动类型自动调整展示重点
- 教练洞察区域是我们独有的差异化（竞品都没有在列表层做AI总结）
- 暗色主题 + 品牌强调色（建议不用绿色避免与 DIGRUN/Sigma 撞色）

### 4.2 运动详情页：推荐方案

**"地图 + 数据 + 教练分析"三段式**

```
┌─────────────────────────────┐
```

## 五、设计风格建议

### 我们应该走什么路线？

| 维度 | DIGRUN 路线 | Sigma 路线 | 我们的路线 |
|------|-----------|-----------|----------|
| 调性 | 潮流/街头/球鞋文化 | 趣味/年轻/可爱 | **专业/克制/高级** |
| 配色 | 黑+荧光绿 | 黑+翠绿 | **暗色+品牌色（建议冷色调：深蓝/暗紫/冰灰）** |
| 数据呈现 | 大字体极简 | 趣味可视化 | **大字体+专业图表** |
| 情绪 | "跑完这一圈，我很酷" | "跑步是件开心的事" | **"每一步都有意义"** |
| 分享卡调性 | 时尚杂志感 | 社交轻量感 | **户外杂志/纪录片感** |

### 为什么这个路线能吸引KOL？

- 跑步KOL分两类：**潮流型**（穿搭+跑步=lifestyle）和**专业型**（成绩+训练=performance）
- DIGRUN/Sigma 已经抢占了潮流型KOL
- 但专业型KOL（越野大神、马拉松PB选手）目前没有一个**既有设计感又够专业**的 App
- 高级感+专业深度的分享卡片，对于专业型KOL来说比"可爱趣味"更有分享欲
- 当潮流跑者看到专业跑者都在用，"向上对标"心理会驱动他们也来——**专业可以吸引潮流，反过来则难**

## 六、优先级建议

| 优先级 | 功能 | 理由 |
|-------|------|------|
| P0 | 运动详情页重设计 | 核心体验页面，每次运动后必看 |
| P0 | 分享卡片（越野数据卡+路跑数据卡） | 自传播核心渠道，用户晒图驱动增长 |
| P1 | 运动历史概览重设计 | 频繁使用但不直接驱动传播 |
| P1 | AI教练分析嵌入详情页 | M3已有能力，需要前端呈现 |
| P2 | 训练周报/月报分享卡 | 有传播价值但非核心 |
| P2 | 成就/里程碑卡 | ITRA分数达成时触发 |
| P3 | 数据贴纸自定义系统 | 锦上添花，优先保证基础卡片质量 |
