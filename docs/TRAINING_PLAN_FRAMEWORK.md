## 1. 竞品训练计划能力对比

### 1.1 主流产品训练计划功能一览

| 产品 | 计划生成方式 | 目标类型 | 科学体系 | 越野支持 | 动态调整 | 计划定价 |
|------|-------------|---------|---------|---------|---------|---------|
| **COROS** | 设备端自动生成 | 马拉松目标时间（sub3/sub330等） | EvoLab（基于跑力值） | 仅基础越野记录 | 根据状态自动调整 | 免费（需 COROS 手表） |
| **Garmin** | Connect App 生成 | 5K/10K/半马/全马目标时间 | Firstbeat（VO2max + 训练负荷） | Garmin Coach 无越野计划 | 有限调整（自适应训练建议） | 免费（需 Garmin 设备） |
| **TrainingPeaks** | 教练手动 + 计划商城 | 自定义（教练设定） | TSS/CTL/ATL/TSB 负荷管理 | 依赖教练经验 | 教练手动调整 | $30-150/份计划 |
| **Strava + Runna** | App 生成 | 5K-马拉松目标时间 | 内部算法（未公开） | 无越野计划 | 根据完成情况调整 | $149.99/年（捆绑） |
| **NRC** | App 内教练计划 | 5K/10K/半马/全马 | 基于 Nike 教练团队经验 | 无 | 无动态调整 | 免费 |
| **Polar** | Polar Flow 生成 | 5K-马拉松目标时间 | Running Index + Cardio Load | 无越野专项 | 根据恢复状态调整 | 免费（需 Polar 设备） |
| **TrainAsONE** | AI 全自动生成 | 5K-超马目标时间 | 机器学习（专利算法） | 基础支持 | 每日自动调整 | $9.99/月 |

### 1.2 关键发现

**市场空白：越野跑训练计划是明显缺口。**

- COROS/Garmin/Polar 的计划生成全部围绕公路跑目标时间（sub3、sub330），无法处理爬升、地形、ITRA 分数
- TrainingPeaks 虽有越野跑教练，但依赖真人经验，且价格 $149-359/月
- 没有任何主流产品支持"目标 ITRA PI → 自动生成越野备赛计划"

**COROS 的计划逻辑（我们的直接参考）：**

```
用户输入: 目标赛事(半马/全马) + 目标时间(如sub330) + 比赛日期
    ↓
系统评估: 当前跑力值 → 判断目标可行性
    ↓
生成计划: 周期化结构（基础期→强化期→减量期）
    ↓
每日训练: 具体配速 + 心率区间 + 距离
    ↓
动态调整: 根据每日 HRV/恢复状态推荐"训练/休息"
```

COROS 的优势在于设备端的生理数据（HRV、恢复时间），但训练理论偏保守、缺乏教练对话能力、完全不支持越野跑。

**我们的机会窗口：**

| 维度 | 竞品现状 | 我们的差异化 |
|------|---------|------------|
| 目标类型 | 仅公路马拉松目标时间 | 公路（目标时间）+ 越野（ITRA PI + km-effort） |
| 计划调整 | 算法自动或教练手动 | AI 对话式调整（"周三我有事"→ 即时重排） |
| 个性化深度 | 基于生理数据 | 生理数据 + 对话记忆 + 训练历史 + 伤病档案 |
| 执行反馈 | 完成率统计 | 每日计划vs实际对比 + 教练点评 |
| 理论透明度 | 黑箱算法 | 教练会解释"为什么这样安排" |

## 2. 公路跑训练科学基础

### 2.1 Daniels VDOT 体系（核心框架）

Jack Daniels 的 VDOT 是公路跑训练的"通用语言"，我们以此作为公路跑计划的理论基础。

**VDOT 值与成绩对应：**

| VDOT | 5K | 10K | 半马 | 全马 |
|------|-----|------|------|------|
| 30 | 27:39 | 57:44 | 2:21:04 | 4:49:17 |
| 35 | 24:03 | 50:03 | 2:02:12 | 4:10:49 |
| 40 | 21:14 | 44:06 | 1:47:48 | 3:42:22 |
| 45 | 19:01 | 39:29 | 1:36:18 | 3:20:35 |
| 50 | 17:13 | 35:47 | 1:27:04 | 3:03:25 |
| 55 | 15:44 | 32:42 | 1:19:35 | 2:49:26 |
| 60 | 14:30 | 30:09 | 1:13:30 | 2:38:01 |
| 65 | 13:27 | 27:57 | 1:08:30 | 2:28:37 |

**五区训练体系：**

| 区间 | 名称 | 强度 | 心率(%HRmax) | 配速(以VDOT50为例) | 目的 |
|------|------|------|-------------|-------------------|------|
| E | Easy（轻松跑） | 低 | 65-79% | 5'41"-6'15"/km | 有氧基础，促进恢复 |
| M | Marathon（马配跑） | 中低 | 80-85% | 4'57"/km | 马拉松专项耐力 |
| T | Threshold（节奏跑） | 中高 | 85-90% | 4'38"/km | 提升乳酸阈 |
| I | Interval（间歇跑） | 高 | 95-100% | 4'15"/km | 提升 VO2max |
| R | Repetition（重复跑） | 极高 | >100% | 3'52"/km | 提升跑步经济性/速度 |

**训练量分配原则：**

```
周跑量 = 用户当前跑量 × 安全增长系数（每周 ≤10%）
E 区间: 70-80% 周跑量
M 区间: 5-10% (仅马拉松备赛)
T 区间: 10-15%
I 区间: 5-8%
R 区间: 2-5%
```

### 2.2 周期化训练结构

**标准马拉松备赛 12-18 周：**

```
Phase 1: 基础期（4-6周）
├── 目标: 建立有氧基础
├── E 区占比 85%+
├── 周跑量逐步提升（每周+10%）
└── 长距离: 从 60min 渐增至 90min

Phase 2: 发展期（4-6周）
├── 目标: 提升乳酸阈和 VO2max
├── 引入 T 和 I 训练
├── 周跑量达峰值
└── 长距离: 90-150min

Phase 3: 专项期（3-4周）
├── 目标: 马拉松专项适应
├── 引入 M 配速训练
├── 背靠背长距离（周六长跑 + 周日中距离）
└── 长距离: 2.5-3h 或 32-35km

Phase 4: 减量期（2-3周）
├── 跑量削减 40-60%
├── 保持少量高强度（维持状态）
└── 最后一次长跑在赛前 2-3 周
```

### 2.3 负荷管理指标

**TSS（Training Stress Score）：**

```
TSS = (训练时间秒 × NP × IF) / (FTP × 3600) × 100
  NP = Normalized Power（标准化功率）
  IF = Intensity Factor（强度因子）= NP / FTP
```

简化跑步版本（rTSS）：

```
rTSS ≈ 训练时间(min) × 强度系数²
  E区: 系数 0.7  → 60min E跑 ≈ 29 rTSS
  T区: 系数 0.9  → 20min T跑 ≈ 16 rTSS
  I区: 系数 1.1  → 12min I跑 ≈ 15 rTSS
```

**CTL / ATL / TSB（训练管理三角）：**

```
CTL（长期训练负荷）= 42天 TSS 指数移动平均 → 反映"体能"
ATL（短期训练负荷）= 7天 TSS 指数移动平均  → 反映"疲劳"
TSB（训练压力平衡）= CTL - ATL            → 反映"状态"
```

```
TSB > 0  → 身体较新鲜，适合比赛或高强度
TSB < 0  → 身体疲劳，在积累训练效果
TSB < -30 → 过度训练风险
比赛日理想 TSB: +5 ~ +25
```

**ACWR（急慢性负荷比）：**

```
ACWR = 最近7天负荷 / 最近28天周均负荷
安全区间: 0.8 - 1.3
危险信号: > 1.5（急性负荷过大）或 < 0.8（训练不足）
```

### 2.4 目标→计划的完整逻辑链（公路跑）

```
输入:
├── 目标赛事: 全马
├── 目标时间: sub 3:30
├── 当前水平: 最近5K 成绩 22:30
├── 比赛日期: 12周后
└── 每周可训练: 5天, 最多8小时

Step 1: 能力评估
├── 5K 22:30 → VDOT ≈ 38
├── 当前马拉松预测: 3:51
└── 目标 sub3:30 → 需要 VDOT ≈ 44

Step 2: 可行性判断
├── 需提升 VDOT 6 点
├── 12周可提升约 3-5 点（合理训练）
└── 结论: 目标略有挑战但基本可行

Step 3: 配速计算（基于目标 VDOT 44）
├── E: 5'24"-5'56"/km
├── M: 4'59"/km
├── T: 4'40"/km
├── I: 4'18"/km
└── R: 3'55"/km

Step 4: 周期划分
├── 基础期: 4周（VDOT 38 配速训练）
├── 发展期: 4周（配速渐进至 VDOT 41-42）
├── 专项期: 2周（VDOT 43-44 配速，含马配跑）
└── 减量期: 2周

Step 5: 生成每日训练
├── 每周模板 × 周期修正
├── 受限于用户约束（5天/周，8小时/周）
└── 长距离安排在周末
```

## 3. 越野跑训练科学基础

### 3.1 ITRA 体系

#### km-effort 公式

赛事难度的统一度量：

```
km-effort = 距离(km) + D+(m) / 100
```

每 100 米爬升等价于 1 公里平路距离。

**赛事分级：**

| 级别 | km-effort | 典型赛事 |
|------|-----------|---------|
| XXS | < 25 | 短距离越野赛 |
| XS | 25-44 | 越野入门赛 |
| S | 45-74 | 中距离越野赛 |
| M | 75-114 | 50km 级别 |
| L | 115-154 | 长距离越野赛 |
| XL | 155-209 | 100km 级别 |
| XXL | >= 210 | 100mi+ 超长距离（UTMB = 271） |

#### ITRA Performance Index（PI）

跑者越野跑能力的标准化分数（200-1000），基于完赛时间与赛道理论参考时间的比值。

**PI 分段参考（男子）：**

| PI 范围 | 水平 | 对应能力 |
|---------|------|---------|
| 800-1000 | 世界精英 | UTMB 前10名 |
| 700-800 | 国家精英 | 职业/半职业 |
| 600-700 | 优秀 | 经验丰富的竞技跑者 |
| 500-600 | 中上 | 认真训练的业余选手 |
| 400-500 | 中等 | 有经验的越野跑者 |
| 300-400 | 入门 | 越野跑新手 |

女子 PI 通常需加约 50-80 分才与男子同等竞技水平对应。

#### 从 PI 估算完赛时间

```
基准速度(km-effort/h) ≈ PI / 系数（55-65，取决于赛道特征）
预期完赛时间(h) = 赛事 km-effort / 基准速度
```

**粗略参考（100km / 5000m D+ 赛事，km-effort=150）：**

| PI | 大约完赛时间 |
|----|-------------|
| 700 | ~12-13h |
| 600 | ~15-16h |
| 500 | ~19-21h |
| 400 | ~25-28h |

### 3.2 越野跑核心度量指标

**为什么用时间+D+而非距离：**

越野跑中同样 10km，平路 50 分钟 vs 山路 2 小时，负荷完全不同。训练负荷核心：

```
越野训练负荷 = f(训练时间, D+, 强度)   而非公路跑的 f(距离, 配速)
```

| 指标 | 公路跑 | 越野跑 |
|------|--------|--------|
| 主要量度 | 周跑量(km) | 周训练时间(h) |
| 辅助量度 | — | 周 D+(m) |
| 强度度量 | 配速(min/km) | 心率区间 / RPE |

**GAP（Grade Adjusted Pace）坡度调整配速：**

基于 Minetti (2002) 坡度代谢成本模型，将坡度跑的实际配速转换为等价平路配速。

```
C(i) = 155.4·i⁵ - 30.4·i⁴ - 43.3·i³ + 46.3·i² + 19.5·i + 3.6
```

| 坡度 | 代谢成本倍数 | GAP 调整 |
|------|------------|---------|
| -10% | ~0.75 | 配速 × 0.75 |
| -5% | ~0.85 | 配速 × 0.85 |
| 0% | 1.00 | 无调整 |
| +5% | ~1.25 | 配速 × 1.25 |
| +10% | ~1.60 | 配速 × 1.60 |
| +15% | ~2.10 | 配速 × 2.10 |
| +20% | ~2.80 | 配速 × 2.80 |

**D+/h（每小时爬升）：**

| 水平 | 持续 D+/h（长距离） | 短距离全力 |
|------|-------------------|-----------|
| 精英男子 | 1000-1200+ | 1500-1800 |
| 优秀 | 700-1000 | 1000-1400 |
| 中等 | 400-700 | 700-1000 |
| 入门 | 200-400 | 400-700 |

### 3.3 越野跑 vs 公路跑训练差异

| 维度 | 公路跑 | 越野跑 |
|------|--------|--------|
| 力量训练 | 辅助，核心稳定 | 核心，臀/股四头肌离心力量 |
| 离心力量 | 较少需求 | 极度重要（下坡冲击） |
| 平衡/本体感觉 | 次要 | 关键（不规则路面） |
| 徒步能力 | 不涉及 | 核心技能（陡坡 power hike） |
| 营养策略 | 赛中补给简单 | 复杂（6-30+ 小时胃肠管理） |
| 装备训练 | 轻量化 | 需适应背包、水袋、登山杖 |
| 夜间能力 | 极少 | 超长赛事必备 |

### 3.4 知名训练方法论

**Jason Koop（CTS）：** 强度优先于量，倒推计划法。适合时间有限的都市越野跑者（8-12h/周）。关键训练课：Steady State（Z3 维持20-45min）、VO2max Intervals（3-5min 高强度间歇）、Over-Under Intervals。

**Uphill Athlete（Steve House）：** AeT（有氧阈值）为王，力量训练周期化。核心概念：AeT-AnT 差距 < 10% 表示有氧基础良好。独特训练课：Muscular Endurance（ME）— 持续爬坡20-60min @ Z3。

**极化训练 / 挪威模式：** 80% Z1 + 20% Z3-Z5，避免"中等强度黑洞"。越野跑天然适用：上坡高强度 + 平路/下坡低强度。

### 3.5 越野跑周期化

**不同距离的备赛周期：**

| 赛事 | 备赛周期 | 巅峰长训 | 力量训练 |
|------|---------|---------|---------|
| 30km 越野 | 12-16周 | 3-4h | 辅助 |
| 50km 越野 | 16-20周 | 4-6h | 核心 |
| 100km 越野 | 20-28周 | 6-8h 或背靠背 | 核心+离心 |
| 100mi 越野 | 24-36周 | 8-12h time-on-feet | 核心+离心+负重 |

**各期结构（以 100km 赛事为例）：**

```
基础期（10-14周）
├── Z1-Z2 有氧 90%+
├── 力量周期化（通用→最大→肌耐力）
├── 周训练 8-12h
└── 周 D+ 1500-2500m

建设期（4-6周）
├── 增加训练量和爬升
├── 引入背靠背长距离
├── 周训练 12-16h
└── 周 D+ 2500-4000m

专项期（4-6周）
├── 赛事模拟地形训练
├── 含 B 赛
├── 周训练 14-18h
└── 周 D+ 3500-5000m

减量期（2-3周）
├── 训练量削减 50-60%
├── 保持少量爬升
└── 周 D+ 1500-2500m
```

**训练 D+ 与赛事 D+ 的关系：**

```
巅峰周 D+ ≈ 赛事 D+ × 80-120%
周均 D+（专项期）≈ 赛事 D+ × 50-80%
周均 D+（基础期）≈ 赛事 D+ × 30-50%
长距离训练 D+/km ≈ 赛事 D+/km × 0.8-1.2
```

### 3.6 越野跑特有训练课类型

| 训练类型 | 描述 | 典型结构 | 目的 |
|---------|------|---------|------|
| 垂直间歇 | 陡坡(15-30%)高强度间歇 | 30-90s全力爬坡 × 8-15组 | VO2max + D+/h |
| 爬坡重复跑 | 缓坡(8-15%)中高强度 | Z3-Z4跑上 × 6-12组 | 可持续爬坡能力 |
| ME 训练 | AeT-AnT间持续爬升 | 20-60min持续爬坡 × 2-4组 | 爬升肌耐力 |
| 长距离山地跑 | Z1-Z2含大量D+ | 3-10h, 1000-3000m D+ | time-on-feet + 脂肪代谢 |
| 背靠背长距离 | 连续两天长距离 | 周六5-8h + 周日2-4h | 模拟赛事后半程疲劳 |
| 下坡重复跑 | 专项下坡技术+离心 | 技术路面下坡 × 多组 | 下坡能力 + 离心适应 |
| 背包训练 | 负重3-5kg长距离 | 专项期长距离中使用 | 装备适应 |
| 夜跑 | 夜间长距离 | 赛前至少3-4次 | 超长赛事必备 |

### 3.7 越野跑能力评估维度

| 维度 | 评估方法 | 关键指标 |
|------|---------|---------|
| 有氧基础 | AeT 心率漂移测试 | AeT效率 = AeT配速 / AnT配速，目标 > 0.85 |
| 爬升能力 | 标准坡度计时爬升 | D+/h @ Z3 强度 |
| 下坡能力 | 赛事前后半程下坡配速衰减 | 下坡效率 = 下坡实际配速 / GAP预测配速，目标 > 0.90 |
| 越野效率 | 越野 vs 平路配速比 | 越野效率指数 = GAP / 实际配速 |
| 长时续航 | 长距离四分位表现衰减 | Q4/Q1 比率，优秀 > 0.85 |
| 负荷风险 | ACWR + 训练量突变 | ACWR 安全区 0.8-1.3 |

### 3.8 赛前减量与赛后恢复

**减量策略：**

| 赛事 | 减量长度 | 训练量削减 | 最后长距离 |

| 50km | 2周 | 40-50% | 赛前2周 |
| 100km | 2-3周 | 50-60% | 赛前2-3周 |

**赛后恢复：**

## 4. 我们的计划生成框架

### 4.1 双轨制：公路 + 越野

我们的计划系统采用双轨制，根据用户目标赛事类型选择不同的理论基础和度量体系：

```
┌────────────────────────────────────────────────┐
│              用户输入目标赛事                    │
│                                                │
│    ┌──────────────┐    ┌──────────────┐        │
│    │ 公路赛事      │    │ 越野赛事      │        │

│           ▼                   ▼                │
│    ┌──────────────┐    ┌──────────────┐        │

│    └──────┬───────┘    └──────┬───────┘        │

```

```python
def assess_feasibility(input: PlanInput, current_ability):
    if input.race_type == "road":
        current_vdot = current_ability.vdot
        target_vdot = time_to_vdot(input.target_time, input.race_distance_km)
        gap = target_vdot - current_vdot
        weeks = (input.race_date - today).days // 7

        # VDOT 提升速率: 初学者 ~1点/周, 中级 ~0.5点/周, 高级 ~0.2点/周
        max_improvement = estimate_max_vdot_gain(current_vdot, weeks)

        if gap <= 0:
            return "目标在当前能力范围内，重点是赛事执行"
        elif gap <= max_improvement * 0.7:
            return "目标合理，正常训练可达到"
        elif gap <= max_improvement:
            return "目标有挑战性，需要高质量训练和良好恢复"
        else:
            return "目标过于激进，建议调整目标或延后赛事"

    else:  # trail
        target_km_effort = input.race_distance_km + input.race_elevation_gain_m / 100
        current_pi = current_ability.itra_pi
        target_pi = input.target_itra_pi
        weeks = (input.race_date - today).days // 7

        # PI 提升速率: 初学者 ~15/月, 中级 ~10/月, 高级 ~5/月
        max_pi_gain = estimate_max_pi_gain(current_pi, weeks)

        # 同时检查赛事规模与用户经验的匹配
        race_level = km_effort_to_level(target_km_effort)
        experience_ok = check_experience_match(race_level, current_ability)

        return feasibility_result
```

#### 4.2.4 周期划分层

```python
def generate_periodization(input: PlanInput, weeks_available: int):
    if input.race_type == "road":
        # 标准公路马拉松周期化
        taper = 2 if weeks_available <= 14 else 3
        base = int(weeks_available * 0.35)
        build = int(weeks_available * 0.30)
        specific = weeks_available - base - build - taper
        return [
            Phase("基础期", base, focus="有氧基础+力量"),
            Phase("发展期", build, focus="乳酸阈+VO2max"),
            Phase("专项期", specific, focus="马配跑+长距离"),
            Phase("减量期", taper, focus="削量保强度"),
        ]

    else:  # trail
        km_effort = input.race_distance_km + input.race_elevation_gain_m / 100

        if km_effort < 75:        # S级: 30km越野
            taper = 1
            base_ratio, build_ratio = 0.45, 0.30
        elif km_effort < 155:     # M-L级: 50-100km
            taper = 2
            base_ratio, build_ratio = 0.40, 0.25
        else:                     # XL-XXL级: 100km+
            taper = 3
            base_ratio, build_ratio = 0.45, 0.20

        base = int(weeks_available * base_ratio)
        build = int(weeks_available * build_ratio)
        specific = weeks_available - base - build - taper
        return [
            Phase("基础期", base, focus="有氧+力量周期化"),
            Phase("建设期", build, focus="增量+爬升+背靠背"),
            Phase("专项期", specific, focus="赛事模拟+B赛"),
            Phase("减量期", taper, focus="削量保爬升感觉"),
        ]
```

#### 4.2.6 渐进式参数增长

```python
def calculate_weekly_progression(phase, week_number, input):
    """每周参数渐进增长（遵守 10% 规则 + 每4周减量）"""

    base_hours = input.recent_weekly_hours
    base_elevation = input.recent_weekly_elevation_m

    # 每周增长率
    if phase.name == "基础期":
        growth_rate = 0.08  # 8%/周
    elif phase.name in ("建设期", "发展期"):
        growth_rate = 0.06  # 6%/周
    else:
        growth_rate = 0.0

    # 每4周安排1周减量（训练量降至70%）
    cycle_week = week_number % 4
    if cycle_week == 3:  # 第4周减量
        multiplier = 0.70
    else:
        multiplier = 1.0 + growth_rate * week_number

    return {
        "weekly_hours": base_hours * multiplier,
        "weekly_elevation": base_elevation * multiplier,
        "long_run_hours": calculate_long_run(phase, multiplier),
    }
```

### 4.3 AI 教练对话式调整

区别于竞品的核心能力：用户通过对话实时调整计划。

```
用户: "周三我有事，能改成休息吗？"
    ↓
教练理解: 周三原定间歇训练需要移动
    ↓
教练判断:
├── 本周已有2个休息日 → 不应再加休息日
├── 间歇课是本周核心 → 不能直接删除
└── 选择: 将周三间歇移至周四，原周四轻松跑移至周五
    ↓
教练回复: "没问题。我把周三的间歇挪到周四，
          周四的轻松跑顺延到周五。周末长距离不变。"
    ↓
update_plan() 工具调用 → 日历自动更新
```

**对话式调整支持的场景：**

| 场景 | 用户输入示例 | AI 处理逻辑 |
|------|------------|------------|
| 时间冲突 | "周三有事" | 移动训练到相邻日 |
| 身体状态 | "最近膝盖有点不舒服" | 减少下坡/高冲击训练，增加交叉训练 |
| 天气因素 | "周六下大雨" | 建议调整为跑步机训练或室内交叉训练 |
| 赛事变更 | "目标赛事改成下个月了" | 重新计算周期划分和减量策略 |
| 主观反馈 | "这周训练太轻松了" | 适当提升下周强度（但不超 ACWR 安全范围） |
| 部分完成 | "长距离只跑了一半" | 评估原因，调整后续计划 |

### 5.2 核心壁垒

1. **越野跑计划 = 无人区**：没有主流产品能根据 ITRA PI 目标自动生成越野备赛计划
2. **对话式调整**：所有竞品的计划调整要么是算法黑箱、要么依赖真人教练，我们用 AI 对话实现"教练级灵活性 + 算法级成本"
3. **持续记忆 + 执行反馈**：教练记住每次训练的执行情况和用户偏好，越用越准

### 5.4 关键公式汇总

| 公式/指标 | 表达式 | 用途 |
|-----------|--------|------|
| km-effort | `距离(km) + D+(m)/100` | 赛事难度量化 |
| VDOT | 查表（成绩→VDOT值） | 公路跑能力量化 |
| GAP | `实际配速 × Minetti坡度系数` | 越野强度统一评估 |
| D+/h | `区间D+(m) / 区间时间(h)` | 爬升能力评估 |
| 越野效率 | `GAP / 实际配速` | 地形适应能力 |
| 续航指数 | `Q4表现 / Q1表现` | 耐力衰减评估 |
| rTSS | `时间(min) × 强度系数²` | 训练负荷量化 |
| CTL | `42天 TSS 指数移动平均` | 长期体能 |
| ATL | `7天 TSS 指数移动平均` | 短期疲劳 |
| TSB | `CTL - ATL` | 训练状态 |
| ACWR | `7天负荷 / 28天周均负荷` | 伤病风险，安全区 0.8-1.3 |
